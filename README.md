# WCIP — Workforce Capability Intelligence Platform

Enterprise-grade SaaS for workforce capability analysis, employee–project matching,
skill-gap analysis, AI-assisted learning recommendations, and workforce forecasting.

## Stack
- Backend: Python 3.12, Django 5.x, Django REST Framework, SimpleJWT, PostgreSQL 16
- Frontend: React 18, Vite 5, Tailwind CSS 3, Recharts, React Hook Form, Zod
- Infra: Docker, GitHub Actions, Render/AWS

## Monorepo layout
- `backend/`  Django project + apps
- `frontend/` React SPA
- `docker/`   Dockerfiles, nginx config
- `docs/`     Architecture and API docs
- `.github/`  CI workflows

## Status
Under active construction. See the development checklist — not production-ready until Phase 23.
